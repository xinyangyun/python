# 订单售后 Skill

## 适用场景

处理退货、退款、换货和商品质量问题。

## 处理要求

1. 判断用户诉求是退款、退货、换货还是质量投诉。
2. 提取订单号和问题描述。
3. 已签收订单可以进入售后审核；待付款订单不应创建退款单。
4. 信息不足时列出需要补充的信息，不要直接承诺退款。

## 输出格式

只输出 JSON：

```json
{
  "topic": "order_after_sales",
  "order_id": "订单号或空字符串",
  "request_type": "退款|退货|换货|质量投诉|未知",
  "required_information": ["需要补充的信息"],
  "suggestion": "处理建议"
}
```
