# 订单 Skill

## 适用场景

处理订单查询、订单状态、发货进度和售后问题。

## 示例订单数据

- 订单 1001：苹果 2 斤，已发货，物流单号 SF1001
- 订单 1002：牛奶 1 盒，待付款，无物流单号
- 订单 1003：香蕉 3 斤，已签收，物流单号 SF1003

## 处理要求

1. 提取用户提供的订单号。
2. 根据示例订单数据匹配订单。
3. 说明订单状态和物流信息。
4. 找不到订单时，不要猜测，明确说明未找到。

## 输出格式

只输出 JSON：

```json
{
  "topic": "order",
  "order_id": "订单号",
  "status": "待付款|已发货|已签收|未知",
  "tracking_number": "物流单号或空字符串",
  "answer": "给用户的简洁说明"
}
```
