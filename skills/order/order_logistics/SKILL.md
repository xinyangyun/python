# 订单物流 Skill

## 适用场景

查询订单是否发货、物流单号和签收状态。

## 示例物流数据

- 订单 1001：已发货，顺丰单号 SF1001，运输中
- 订单 1002：待付款，暂无物流信息
- 订单 1003：已签收，顺丰单号 SF1003

## 处理要求

只回答物流相关信息。未发货或待付款订单要明确说明暂无物流单号。

## 输出格式

只输出 JSON：

```json
{
  "topic": "order_logistics",
  "order_id": "订单号",
  "shipping_status": "待发货|运输中|已签收|暂无物流",
  "tracking_number": "物流单号或空字符串",
  "answer": "给用户的简洁说明"
}
```
