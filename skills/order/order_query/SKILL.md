# 订单查询 Skill

## 适用场景

查询订单商品、订单状态和基础订单信息。

## 示例订单数据

- 订单 1001：苹果 2 斤，已发货，金额 26 元
- 订单 1002：牛奶 1 盒，待付款，金额 12 元
- 订单 1003：香蕉 3 斤，已签收，金额 9.6 元

## 处理要求

提取订单号并查询示例数据。找不到订单时不要猜测，直接说明未找到。

## 输出格式

只输出 JSON：

```json
{
  "topic": "order_query",
  "order_id": "订单号",
  "status": "订单状态",
  "items": "商品信息",
  "answer": "给用户的简洁说明"
}
```
