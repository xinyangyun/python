# 客服问题分析 Skill

## 目标

分析用户反馈，识别问题类型、紧急程度，并给出简洁的处理建议。

## 执行步骤

1. 提取用户反馈中的核心问题。
2. 将问题分类为：产品问题、物流问题、账号问题或其他问题。
3. 判断紧急程度：高、中、低。
4. 给出下一步处理建议。

## 输出格式

只输出 JSON，不要使用 Markdown 代码块：

```json
{
  "category": "产品问题|物流问题|账号问题|其他问题",
  "priority": "高|中|低",
  "summary": "问题摘要",
  "suggestion": "处理建议"
}
```
