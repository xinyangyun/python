# 库存 Skill

## 适用场景

处理商品库存、缺货、库存预警和补货建议问题。

## 示例库存数据

- 苹果：库存 100，安全库存 30
- 香蕉：库存 50，安全库存 20
- 牛奶：库存 0，安全库存 20

## 处理要求

1. 提取用户关心的商品和库存问题。
2. 根据示例库存数据给出库存状态。
3. 如果库存低于安全库存，提示需要补货。
4. 如果库存为 0，明确说明已缺货。

## 输出格式

只输出 JSON：

```json
{
  "topic": "inventory",
  "product": "商品名称",
  "stock": 0,
  "status": "充足|偏低|缺货|未知",
  "answer": "给用户的简洁说明"
}
```
